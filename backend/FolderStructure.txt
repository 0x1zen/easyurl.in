src/
  config/        → env loading, DB connection pool setup
  routes/        → just maps a URL path to a controller function — no logic here
  controllers/   → handles the HTTP layer (reads request, sends response)
  services/      → the actual business logic (e.g., short code generation, plan checks)
  middleware/    → cross-cutting concerns (auth check, rate limiting, error handling)
  types/         → shared interfaces matching your DB tables (Subscriber, Url, Plan...)
  utils/         → small reusable helpers (e.g., Base62 encode/decode)
  index.ts       → entry point — wires everything together, starts the server

  Remember : Separation of concerns
